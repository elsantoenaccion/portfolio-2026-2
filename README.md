# Sergio Ruiz Trejo — sitio web

Sitio personal y profesional de Sergio Ruiz Trejo. HTML y CSS estáticos, desplegados en Vercel desde GitHub.

## Estructura
- `index.html`: portada.
- `proyectos.html`: práctica institucional, museos y acervos.
- `procesos.html`: investigación artística y modos de trabajo.
- `obra.html`: selección de piezas y registro de La voz.
- `textos.html`: publicaciones, capítulo de libro y tesis.
- `sobre.html`: semblanza, formación, residencias y contacto.
- `styles.css`: identidad visual original de la portada.
- `interiores.css`: diseño adaptable de las páginas interiores.
- `assets/`: fotografías y recursos visuales.
- `vercel.json`: URLs limpias y configuración de despliegue.
- `CONTENIDOS.md`: procedencia de contenidos y pendientes editoriales.

## Desarrollo

No requiere dependencias ni compilación. Servir la raíz con un servidor HTTP de archivos estáticos.
La navegación y los detalles desplegables funcionan sin JavaScript.

## Revisión

La primera propuesta de páginas interiores se desarrolla en `codex/paginas-interiores`.
Vercel puede generar una vista previa para revisar diseño, textos y selección antes de integrar los cambios en `main`.
